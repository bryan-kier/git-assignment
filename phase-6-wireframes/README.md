## Design direction

- **Style**: dark, image-centric, scroll-driven "brochure" feel — sticky nav, hero parallax, scroll-reveal sections. Desktop-first for now.
- **Palette**: near-black ground, crimson-red accent, warm off-white text, graphite neutrals. Colors are adapted from a Velox-branded moodboard shared during design (color/typography direction only — the falcon logo and "Velox" name are a separate designer's actual brand identity and were **not** reused).
- **Product imagery**: jerseys are rendered as vector graphics (SVG), not photos — built to echo the SWAZ jersey-mockup template style (crew-neck collar trim, shield crest containing a generic jersey glyph, "SPONSOR" placeholder chest text, diagonal/yoke/side-panel pattern treatments) but with no real club or league branding, since this business resells unofficial imports and can't imply league/club licensing.
- **Category naming**: uses descriptive labels ("Football Kits", "Basketball Jerseys", "Streetwear & Collabs") instead of league names (NFL, EPL, etc.) to avoid implying official partnership — flagged for the Phase 1 owner to confirm with the team.
- **Currency**: PHP (₱) throughout, consistent with PH-only shipping from Phase 4.
